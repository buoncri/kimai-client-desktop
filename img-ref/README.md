# Immagini di riferimento

Queste immagini **non sono opera nostra**: sono screenshot del client desktop
ufficiali KEMAI, scaricati dalla pagina del marketplace Kimai e usati come
riferimento visivo per riprodurre il layout in Tkinter.

Origine: https://www.kimai.org/en/store/alexandreptj-kemai-desktop-client.html
Autore delle schermate: il client KEMAI di Alexandre Petitjean.

| File | Vista | Origine |
|---|---|---|
| `kemai-settings.webp` | finestra di connessione | kimai.org /images/marketplace/ |
| `kemai-running.webp` | timer in esecuzione | kimai.org /images/marketplace/ |
| `kemai-add-project.webp` | dialog di creazione progetto | kimai.org /images/marketplace/ |

I file `.webp` sono gli originali scaricati dal sito. I `.png` sono conversioni
lossless prodotte con ffmpeg per poterli ispezionare piu comodamente; i pixel
sono identici.

Non sono asset dell'applicazione: il nostro client genera la propria icona a
runtime con Pillow, senza file binari nel repository.
